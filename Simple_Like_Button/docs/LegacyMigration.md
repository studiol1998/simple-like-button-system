# 旧ベータ版からの移行メモ

旧PHPベータ版は、参照用として `../legacy/like_button_beta_package/` に保存しています。新しい実装では、親ディレクトリにあるv1.0仕様書を正式な基準とします。

## 引き継ぎ候補

| ベータ版の機能・構成 | Pollyannaでの方針 |
| --- | --- |
| シンプルなHTML埋め込みとJavaScriptウィジェット | 簡単に埋め込める考え方は維持し、仕様に定めた不透明な `identifier` を使用します。通信エラーも処理します。 |
| いいねAPIと件数取得APIの分離 | 分離を維持し、API仕様に基づいて入力、HTTPメソッド、応答形式、ステータスコードを定義します。 |
| DB操作をサービスクラスに集約 | DB操作をサービス層にまとめ、現行のデータ・プライバシー方針に従います。 |
| SQLによるインストール | DB構築の手順は維持し、ベータ版のテーブルではなく現行スキーマを使います。 |
| 有効・メンテナンス・停止のモード | 現行の管理・設定仕様に合わせて扱いを決めます。 |
| 6時間で10回の制限 | ベータ版の初期値候補として扱い、確定したレート制限仕様に従います。 |

## ベータ版の既知の課題

- `page_id` は最大255文字ですが、現行設計の `identifier` は最大50文字です。
- IPアドレスを通常のSHA-256でハッシュしています。現行設計では、設置ごとの秘密鍵を使ったHMACを指定しています。
- IPアドレスを全体共通の制限に使い、クライアントハッシュや同時アクセス時の扱いを定義していません。
- 書き込みAPIはJSONや識別子を十分に検証せず、DB登録の成否も確認していません。
- 件数取得APIは識別子やHTTPメソッドを検証していません。
- JavaScriptはURL内の識別子を安全にエンコードせず、応答が成功する前提になっています。
- 設定ファイルには仮のDB接続情報があり、秘密鍵の生成やインストール後の安全確認もありません。

ベータ版は意図された動作を調べるための資料として使い、現行仕様に沿って実装し直します。保存されたベータ版をそのまま本番環境に配置しないでください。
