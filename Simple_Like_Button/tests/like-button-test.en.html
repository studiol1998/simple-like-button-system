Pollyanna Beta 0.0.3 Manual Check

Tap ♡. After the server saves the Like, it changes to a filled, colored ♥ and displays “Good!” for 0.5 seconds.

Test identifier: xampp-state-test-001

Steps

  1. Start Apache and MySQL, configure the database connection, and run install/install.sql.
  2. Tap ♡ on this page. After a successful save, confirm that ♥ appears and “Good!” disappears after 0.5 seconds.
  3. Reload the page and confirm that the same browser restores the ♥ state.
  4. In a different browser, confirm that it starts at ♡ if it has not liked this identifier, then confirm that its ♥ state also returns after reload.
  5. Set show_like_count to true in config/config.php. Reload and confirm that the count appears and increases after a Like. Set it back to false and confirm that the count is hidden.
  6. In phpMyAdmin, open pollyanna_likes and confirm that a row with identifier xampp-state-test-001 was added.

Check: The restored ♥ state is determined by saved data for the same browser and identifier. Clearing LocalStorage makes the browser appear as a new one. Count display is off by default.
