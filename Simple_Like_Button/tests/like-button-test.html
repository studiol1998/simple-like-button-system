Pollyanna β-0.0.2 手動確認

♡をタップし、サーバーへの保存が成功すると色つきの♥に変わり、「Good!」が0.5秒間表示されます。

テスト対象：xampp-state-test-001

確認手順

  1. Apache と MySQL を起動し、DB設定と install/install.sql の実行を済ませます。
  2. このページで♡をタップし、保存成功後に♥へ変わり、「Good!」が0.5秒後に消えることを確認します。
  3. ページを再読み込みし、同じブラウザでは♥表示に戻ることを確認します。
  4. 別のブラウザでは未押下なら♡表示になり、そのブラウザで押した後の再読み込みでは♥表示に戻ることを確認します。
  5. phpMyAdminで pollyanna_likes を開き、identifier が xampp-state-test-001 の行が追加されたことを確認します。

確認内容：♥の復元状態は同じブラウザ・同じ識別子ごとに保存済みデータから判定されます。LocalStorageを消去すると別のブラウザとして扱われます。
