# Pollyanna Design Principles

## Philosophy

Pollyanna is an independent Like-button engine.

It does not understand pages, CMSs, URLs or HTML structures. It only
stores and counts Likes for an **Identifier** supplied by the host page.

## Principles

1.  Simple
2.  CMS independent
3.  HTML structure independent
4.  Identifier-based
5.  Lightweight
6.  Secure by default
7.  Extensible
8.  Specification-first development

## Identifier

An Identifier is any unique string chosen by the site owner.

Examples:

-   novel_001
-   blog-2026-09-23
-   格納庫・桜《外》（喪失。）

Pollyanna never interprets its meaning. It only stores and aggregates
Likes by Identifier.
