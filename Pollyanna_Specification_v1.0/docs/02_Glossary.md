# Glossary

-   Identifier: Unique string identifying a Like target.
-   Installer lock: State after successful web installation in which Admin remains unavailable until the entire `install/` directory is deleted.
-   Environment check: Installer validation of PHP extensions, sessions, writable configuration storage, schema availability, and access-protection files.
-   client_hash: Browser identifier hash.
-   ip_hash: HMAC-SHA-256 hash of client IP.
-   Secret Key: Installation-specific cryptographic key.
